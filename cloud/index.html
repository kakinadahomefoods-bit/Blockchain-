TECHNICAL OVERVIEW

One academic project.
Two execution environments.

Separate the realistic local face-recognition workflow from this safe browser demonstration.

01RegistrationPrivate identity data
02VerificationFaculty / local OpenCV
03RecordingSolidity or demo hash chain
04ReportingInspectable event history

Full local application

The downloadable source includes an independently run FastAPI server, OpenCV face recognition and a Solidity contract deployed to a Ganache EVM for classroom demonstrations.

01
Registration & consent

Store private face descriptors separately from the audit records.

02
Recognition & review

Compare image features locally; a camera match is not a liveness check.

03
On-chain session events

Faculty actions use pseudonymous tokens on an educational Solidity ledger.

04
Traceable records

Inspect session creation, attendance and correction history.

Vercel preview scope

A responsive, interactive interface powered by local browser storage and the Web Crypto API. It needs no student data, passwords or biometric uploads to demonstrate the workflow.
